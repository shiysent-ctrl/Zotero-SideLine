# 本机 HTTP 接口

0.11.0 保留 19 个端点。它们由 Zotero 本机 HTTP 服务提供，默认地址为 `http://127.0.0.1:23119`；只接受下表所列方法，POST 使用 `Content-Type: application/json`。响应是 JSON，不回显服务商密钥。没有独立鉴权，本机程序可调用。

条目参数 `itemID` 是 Zotero 数字 ID，不是条目 key。以下表格用于识别能力与副作用，详细字段以 `src/modules/endpoints.js` 为准。只读检查优先使用 `status` 和 `selftest`；模型调用及写入须由调用者明确发起。

| 方法 | 路径 | 主要参数与行为 |
|---|---|---|
| GET | `/sideline/status` | 状态、配置摘要、功能和端点清单，不含密钥 |
| POST | `/sideline/selftest` | 可选 `itemID`；检查注册、配置及条目正文，不调用模型 |
| POST | `/sideline/context` | `itemID`；可选 `mode`、`maxChars`、`selection`、`includeText`；读取上下文 |
| POST | `/sideline/chat` | `itemID`、`question` 或 `functionId`；非流式问答。`provider` 支持 `api`/`agent`，旧 `deepseek`/`codex` 兼容读取；`save:true` 创建子笔记 |
| POST | `/sideline/note` | `itemID`、`answer`；可选 `question`、`model`、`source`；直接新建子笔记 |
| POST | `/sideline/sessions` | 空对象列存档；`itemID` 读取本篇会话、附件与写入记录 |
| POST | `/sideline/sessions/delete` | `itemID`；清空本篇消息/存档并重置 Agent；保留已写笔记与批注 |
| POST | `/sideline/sessions/search` | `itemID`、`query`；可选 `maxHits`、`contextChars`；检索本篇会话 |
| POST | `/sideline/sessions/export` | `itemID`；可选 `format`（`markdown`/`json`）、`sessionId`、`includeText`、`maxChars`；只有给 `path` 才写文件 |
| POST | `/sideline/functions` | 四功能的 ID、名称、范围及自定义状态，不返回完整提示词 |
| POST | `/sideline/provider` | 当前通道、Agent 与模型、图片支持摘要，不含密钥 |
| POST | `/sideline/summary` | `itemID`；默认 `action:"prompt"` 返回结构化模板与覆盖信息；`action:"preview"` 与 `answer` 返回写入计划，`action:"commit"` 加 `confirm:true` 才写入；可选替换标志需调用者明确指定 |
| POST | `/sideline/notes/search` | `itemID`；可选 `query`、`maxHits`、`contextChars`；读取笔记与命中片段 |
| POST | `/sideline/inputs/resolve` | `value`；可选 `itemID`、`includeText`、`includeFulltext`；材料解析预览，不自动加入对话 |
| POST | `/sideline/excerpt` | `itemID`、`messages` 或 `question`/`answer`；默认 `action:"preview"`；`action:"commit"` 加 `confirm:true` 新建带来源的子笔记 |
| POST | `/sideline/diag/codex` | 固定子进程/CLI 诊断；`probe:"version"` 不调用模型；其它探测按源码契约操作 |
| POST | `/sideline/diag/reader` | 阅读器文本层结构探测，不写批注 |
| POST | `/sideline/diag/readertext` | 按页正文、纸面页码、覆盖状态与文字定位探测 |
| POST | `/sideline/diag/sessions` | `probe:"resolve"` 读取会话附件；`probe:"write"` 写一次插件会话自检内容 |

## 只读自检

在 Zotero 已运行并启用插件时执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-endpoints.ps1
```

检查指定条目的正文：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-endpoints.ps1 -ItemID 1234
```

`1234` 是示例，替换为测试条目 ID。脚本添加 `-Chat` 会执行模型请求；未指定时不主动推理。不要把写入接口混进只读健康检查。

## 接口维护约束

- 每个端点类的 `init(request)` 保留恰好一个形参，Zotero 据此选择返回值契约；保留 `supportedMethods`、`supportedDataTypes` 与 `permitBookmarklet:false`。
- `chat` 的 Agent 请求并入本篇唯一会话，响应带原生 `sessionId` 和可能的 `sessionWarning`。API 请求仍按调用方给定历史工作；不要把“一次性 HTTP 响应”误解为每次新建 Agent 会话。
- 外部写入授权由调用方控制；`note` 及 `chat(save:true)` 不另弹界面确认。`summary` 与 `excerpt` 的提交必须先预览并明确给 `confirm:true`。
- 不提供任意命令执行或任意坐标批注接口。PDF 批注依赖阅读器选区或本地正文匹配，并在界面显式确认。
- 不删除仍有效的旧端点，也不在响应中添加密钥、思考正文、工具参数或个人诊断文件。
