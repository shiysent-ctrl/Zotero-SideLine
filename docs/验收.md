- [ ] API 模型可编辑、列表可选择；刷新读取目录，输入变更清除旧连接状态。未测试为红色，真实成功为绿色，失败原因可读。
- [ ] 文字与视觉分别测试，沿用文字基址/密钥不跳过视觉测试；视觉超时独立。实际视觉请求不出现 `responseText` 类型错误。
- [ ] API 综合测试只有文字、视觉都成功才为绿色；失败能区分通道。Agent 综合测试只走当前 Agent，不依赖 HTTP 设置。
- [ ] 扫描前 Agent 框为空，扫描后提示选择；选择不自动检测。添加另一指定路径不清空当前选择；路径重置不删除实际安装。
- [ ] 离线检测后“模型列表已刷新，请选择模型”；模型只能从列表选择，选择后“模型选择完成，请验证请求协议”。
- [ ] 协议成功后“思考协议验证完成，请选择思考强度”；选强度含默认后“请测试连接状态”。失败与过期响应不能宣称完成，更换 Agent/模型清除旧能力。
- [ ] 不支持图片的 Agent 模型给出具体原因，不回退其它通道；逐模型能力不由此次三个成功样本推断。
- [ ] 三个 Agent 默认拒绝文件、终端及未知工具；关闭搜索时无检索许可，启用后实际搜索/网页读取仍按白名单验证。
