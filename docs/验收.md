### 会话和材料

- [ ] 四功能及独立提示词生效；当前页/全文覆盖可见，选区、笔记、文本和图片可加入/预览；非法路径或取文失败有原因，扫描页提示需要文字层。

### 定位、写入和撤销

- [ ] 普通页码跳页，完整引文定位并短暂高亮；失败只跳页，不用短前缀冒充完整命中。
- [ ] 短文显式高亮后出现原生批注、评论及逐条颜色，可编辑，关闭重开后保留；通知及时更新已打开阅读器。
- [ ] 双栏、旋转页、公式、重复原文及混合断词位置可靠；无法确认的几何/歧义失败，不把正文相似分数当作公式语义核验。
- [ ] 长文分段覆盖与用量反馈可核对；失败在原气泡汇总，未完成部分不冒称成功，重试不重复请求成功段。
- [ ] 创建批次 A 并编辑其中一条，再创建 B；从 A 回复撤销只删除 A 未编辑对象，保留编辑项和 B，回执计数与实际对象一致；重启后仍可按旧批次撤销。
- [ ] 普通回答隐藏后提问和后续消息保留，重启仍隐藏；下一轮 API/Agent 使用原历史，不重置原生会话或额外重放。
- [ ] 缺少父文献、关闭会话保存、附件预检失败时在模型调用前停止高亮；批注日志未完成或中断对象无法核验时不猜测删除。
- [ ] 对应回复菜单保存该回答及提问为新子笔记，带来源，不混后续回复、不覆盖旧笔记；高亮仅保存可读回执。
- [ ] 划词保存批注受开关控制，没有可靠坐标则禁止；侧栏显式自动高亮独立授权，既有批注不变。
- [ ] 结构化总结 preview 不写入，commit 要求 confirm:true；标签只追加，已有短总结及 fixed marker 保留。
- [ ] 本机 19 个端点正常注册且不回显密钥；只读自检不调用模型，诊断写入只处理本插件会话附件。

通过自动化不等于安装、视觉、真实模型或原生写入通过；实际失败记录触发条件、错误及影响，再决定发布范围。
